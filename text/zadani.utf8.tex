\nadepsanaSranka{Assignment}
 \begin{enumerate}
       \item Study the issues of S-boxes in cryptography. Furthermore, study evolutionary computation techniques, such as genetic algorithms, EDA algorithms, and Cartesian genetic programming.
       \item Design a program for evolutionary design of S-boxes using individual methods.
       \item Implement the designed program in a suitable language and environment.
       \item Compare individual approaches on selected examples and evaluate the achieved results.
 \end{enumerate}
